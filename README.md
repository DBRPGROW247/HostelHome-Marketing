# HostelHome — Public Marketing & Compliance Website

This repository contains the standalone, high-performance static public marketing and regulatory compliance website for **HostelHome**.

## 📁 Structure

```
HostelHome-Marketing/
├── index.html                  # Official Marketing Landing Page & Product Showcase
├── about.html                  # About Us & Platform Vision
├── pricing.html                # Pricing Tiers & Subscription Features
├── contact.html                # Sales & Support Contact
├── merchant-upi-guide.html     # Automated PhonePe/UPI Merchant Integration Guide
├── delete-account.html         # Google Play Store Mandatory Account Deletion Form
├── privacy-policy.html         # Digital Personal Data Protection (DPDP) Privacy Policy
├── privacy.html                # Privacy Policy Alias / Redirect
├── terms.html                  # Terms & Conditions / Service Agreement
├── refund-policy.html          # Cancellation & Refund Policy
├── refund.html                 # Refund Policy Alias
├── google72b9f571543a2a80.html # Google Search Console Verification
├── robots.txt                  # Search Engine Crawl Directives
├── sitemap.xml                 # Canonical XML Sitemap
├── _headers                    # Cloudflare Pages Custom Caching & MIME Headers
├── dark-mode.css               # Shared Dark / Light Theme Tokens
├── legal.css                   # Typography & Spacing for Legal Documents
├── skeleton.css                # Loading Skeleton Styles
├── icons/                      # Brand Logos & Favicon Assets
└── scripts/                    # Lightweight UI Utilities (ui-core.js, android-bridge.js)
```

## 🚀 Deployment
Deployable with zero configuration to **Cloudflare Pages**, **Vercel**, **Netlify**, or **GitHub Pages**.
